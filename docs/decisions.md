## D-002: Стек — vanilla HTML / CSS / JS, разметка только через createElement

- Status: Accepted
- Date: 2026-10-03
- Почему: запрещённый способ создания DOM и сторонние UI-библиотеки дают −100

- HTML + CSS + чистый JavaScript. ES modules допустимы.
- Вся разметка приложения создаётся через `document.createElement` или тонкую обёртку над ним. В исходном `<body>` только тег `script`. CSS подключается из `<head>`.
- Запрещены присваивания `innerHTML` и `outerHTML` (включая пустую строку), `insertAdjacentHTML`, `document.write`, `document.writeln`, разбор HTML-строк через `DOMParser` или `Range.createContextualFragment`.
- Запрещены `alert`, `confirm`, `prompt`.
- Запрещены сторонние библиотеки и фреймворки для интерфейса, DOM или игровой логики. Сборщики, линтеры и тесты допустимы.
- Референс [flowforfrank/memory-game](https://github.com/flowforfrank/memory-game/blob/master/assets/game.js) — только идея механики. Его `innerHTML` / `DOMParser` не переносить.

## D-004: Структура исходников — одна страница, модули по ответственности

- Status: Accepted
- Date: 2026-10-03
- Почему: задание требует пустой `body` и разделение логики на функции с понятной ответственностью

```text
index.html          → пустой body + <script type="module">
css/                → base, components
js/
  main.js           → сборка экрана, старт, связь модулей
  dom.js            → обёртка createElement
  cards.js          → 8 пар
  shuffle.js        → Фишер–Йейтс
  game.js           → состояние и правила, без модалок
  board.js          → поле и клики
  header.js         → кнопки хедера и счётчики
  modal.js          → общая оболочка
  leaderboard.js    → localStorage и содержимое таблицы
assets/images/      → лица пар и рубашка
docs/               → SDD (не в runtime)
```

Детали: [specs/architecture.md](./specs/architecture.md).

## D-007: Поле 4×4, один набор из 8 пар, задержка несовпадения 1000 мс

- Status: Accepted
- Date: 2026-10-03
- Почему: размер поля фиксирован заданием, а задержка должна попасть в диапазон 700–1500 мс

- 16 карточек, 8 разных изображений, каждое дважды. Один и тот же набор во всех играх.
- Лицо карточки — `img`, файлы в `assets/images/`. Рубашка одинаковая и не показывает лицо.
- Конкретные картинки выбраны в D-009. Художественное качество не оценивается; источник и лицензию указать в README, если они не свои.
- Несовпавшая пара закрывается через **1000 мс**. Перемешивание — Фишер–Йейтс, не набор готовых раскладок.
- Таймер прохождения, звук, уровни сложности и очки за анимацию не делаем: задание за них баллы не даёт.
