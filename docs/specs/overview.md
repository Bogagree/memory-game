# Product & domain overview

## Что это

Игра на поиск пар: 16 карточек, 8 пар. Игрок открывает две карточки за ход и ищет все совпадения за наименьшее число ходов. После победы результат попадает в таблицу лидеров в `localStorage`.

Интерфейс на русском ([D-008](../decisions.md)). Дизайн свободный.

## Правила

1. Игра начинается при загрузке и при каждой перезагрузке. Карточки перемешаны и лежат рубашкой вверх. Ходы — 0, пары — 0 из 8. Игрок сразу может открывать карточки. Отдельной кнопки «Старт» нет.
2. Один ход — открытие двух разных доступных карточек, совпали они или нет.
3. Совпавшая пара остаётся открытой до конца игры. Счётчик пар +1.
4. Несовпавшая пара видна **1000 мс** ([D-007](../decisions.md)), затем закрывается. Пока она открыта, другие карточки выбрать нельзя. Кнопки хедера в этот момент доступны, если модалка не открыта.
5. Когда найдены все 8 пар, открывается модалка победы: текст, число ходов, «Новая игра» и «Закрыть».
6. «Новая игра» перемешивает и закрывает карточки, обнуляет счётчики, без перезагрузки страницы. Незавершённая игра в рейтинг не пишется.
7. «Таблица лидеров» показывает до 10 лучших результатов и не сбрасывает текущее поле.

Полный контракт состояния: [game.md](./game.md).

## Вне скоупа

- Таймер прохождения, звук, уровни сложности, несколько наборов картинок.
- Копирование разметки из [flowforfrank/memory-game](https://github.com/flowforfrank/memory-game/blob/master/assets/game.js).

## Критерии (резюме)

| Блок | Баллы |
| --- | --- |
| Генерация разметки | 15 |
| Начало игры | 10 |
| Перемешивание | 5 |
| Выбор карточек | 15 |
| Несовпавшие пары | 10 |
| Счётчики | 5 |
| Модальные окна | 15 |
| Таблица лидеров | 10 |
| Новая игра | 15 |
| README | +5 |

Штрафы по −100: не `createElement`, запрещённые HTML-API, `alert`/`confirm`/`prompt`, сторонняя UI-библиотека. По −30: нет доступного PR или нет доступного деплоя. По −10: коммиты не по [git convention](https://rs.school/docs/git-convention). Итог не больше 100 и не меньше 0.

Генерация разметки и перемешивание проверяются по коду. Случайное повторение раскладки допустимо.
