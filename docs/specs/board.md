# Board

## Scope

- 16 карточек: 8 `pairId`, каждый дважды ([D-007](../decisions.md)).
- При загрузке, перезагрузке и «Новой игре» все лежат рубашкой вверх. Рубашки одинаковые.
- Лицо — `img` из `assets/images/`. Пара визуально совпадает, разные пары легко отличить.
- Перемешивание — Фишер–Йейтс в `js/shuffle.js` при каждом `startGame`. Выбор из заранее заготовленных раскладок не подходит. Одинаковая случайная раскладка два раза подряд допустима.

## Карточка

У карточки два слоя: рубашка и лицо. Класс открытой карточки показывает лицо. Найденная пара остаётся открытой и не реагирует на клик.

Клик слушается на карточке. Решение, открывать ли её, принимает [game.md](./game.md), не разметка.

## Шаги

- `feat/board` — 16 закрытых карточек сразу после загрузки, счётчики на нуле, кнопки хедера доступны.
- `feat/shuffle` — порядок этих карточек случайный при каждой загрузке. Та же функция позже вызывается из «Новой игры».
