# Leaderboard

## Scope

Кнопка хедера открывает модалку ([modal.md](./modal.md)) со списком до **10** лучших партий и кнопкой «Закрыть». Если записей нет — текст «Пока нет результатов», без пустой таблицы.

Просмотр и закрытие не меняют поле и счётчики. Если при открытии идёт таймер несовпавшей пары, он доигрывает за окном и карточки закрываются как обычно.

## Строка результата

| Колонка | Правило |
| --- | --- |
| Место | 1…10 после сортировки |
| Ходы | число ходов завершённой партии |
| Дата | `ДД.ММ.ГГГГ`, без времени |

Сортировка: меньше ходов выше. При равных ходах выше более ранняя партия. Для этого в записи хранится полный момент победы, на экран выводится только календарная дата.

## Хранение

- Ключ `localStorage`: `memory-game-results`.
- Значение: JSON-массив `{ moves: number, playedAt: string }`. `playedAt` — ISO-время победы.
- Запись добавляется один раз при переходе партии в `won`. Повторное открытие модалок и «Закрыть» дубликат не создают.
- В хранилище можно держать всю историю. На экране — первые 10 после сортировки.
- «Новая игра» ключ не очищает. Незавершённая партия не сохраняется.
- После перезагрузки страницы и повторного открытия браузера список на месте.
