# Counters

## Scope

На странице видны два значения:

- число ходов;
- число найденных пар в виде «0 из 8».

В начале партии оба нули. Подписи можно сформулировать иначе, смысл сохранить.

## Когда меняются

- Ход +1 в момент открытия **второй** карточки пары, независимо от совпадения.
- Пары +1, когда два лица совпали.
- Клик, который не открывает новую карточку, счётчики не меняет: уже открытая, уже найденная, третья во время `locked`, любой клик после победы.
- «Новая игра» возвращает оба значения к нулю.

Обновление текста — через `textContent` из состояния игры, не из ручного пересчёта DOM.
