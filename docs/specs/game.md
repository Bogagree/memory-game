# Game

Связано: [board.md](./board.md), [counters.md](./counters.md), [modal.md](./modal.md), [leaderboard.md](./leaderboard.md).

## Состояние

```text
cards: { id, pairId, isFaceUp, isMatched }[16]
moves: number
matchedPairs: number
phase: idle | oneOpen | locked | won
openCardId: id | null
mismatchTimerId: timeout id | null
resultSaved: boolean
```

`idle` — нет открытой ненайденной карточки. `oneOpen` — открыта первая, ждём вторую. `locked` — две несовпавшие карточки на экране. `won` — найдены 8 пар.

## Открытие карточки

Клик игнорируется, если фаза `locked` или `won`, карточка уже лицом вверх или уже `isMatched`. Повторный клик по той же карточке не считается ходом и не матчит её саму с собой.

- Из `idle`: открыть карточку, запомнить `openCardId`, фаза `oneOpen`. Счётчики не меняются.
- Из `oneOpen` по другой закрытой карточке: открыть её, `moves += 1`, затем сравнить `pairId`.
  - Совпали: обе `isMatched`, `matchedPairs += 1`, `openCardId = null`, фаза `idle`. Если пар стало 8 — фаза `won`.
  - Не совпали: фаза `locked`. Через 1000 мс закрыть обе, если таймер не отменён, и вернуть `idle`.

Пока фаза `locked`, клики по карточкам не открывают третью. Кнопки хедера при этом работают, если нет открытой модалки.

## Победа

При переходе в `won` результат пишется в рейтинг ровно один раз (`resultSaved`). Затем открывается модалка победы. После её закрытия клики по карточкам не меняют поле и счётчики.

Открытие и закрытие модалок само по себе записей не создаёт.

## Новая игра

Одна функция для кнопки хедера и кнопки в модалке победы:

1. `clearTimeout` у `mismatchTimerId`, даже если 1000 мс ещё не прошли.
2. Закрыть модалку победы, если она открыта.
3. Заново собрать 16 карточек, перемешать, все рубашкой вверх.
4. `moves = 0`, `matchedPairs = 0`, `phase = idle`, `openCardId = null`, `resultSaved = false`.

Рестарт не ждёт старый таймер и не удаляет прошлые результаты. Незавершённая партия в рейтинг не попадает. Кнопка работает и во время партии, и после победы.

## Шаги

- `feat/flip-pair` — клик открывает первую карточку и ждёт вторую. Совпавшая пара остаётся лицом вверх, после этого можно открыть следующую. Повторный клик по уже открытой или найденной карточке игнорируется. Несовпавшая пара тоже остаётся открытой, фаза становится `locked`, третья карточка не открывается. Счётчики не меняются. Таймера нет.
- `feat/mismatch-counters` — несовпавшая пара закрывается через 1000 мс, затем можно выбирать снова. Ход считается при открытии второй карточки, пара — при совпадении. Восьмая пара ставит фазу `won` и больше не принимает клики. Модалка победы, рейтинг и отмена таймера кнопкой «Новая игра» в этот шаг не входят.
- `feat/win-modal` — переход в `won` один раз открывает модалку победы. Закрытие не сбрасывает поле и счётчики. Рестарт и запись в рейтинг в этот шаг не входят.
- `feat/leaderboard` — тот же переход один раз пишет результат в `localStorage`. Кнопка «Таблица лидеров» открывает рейтинг и не сбрасывает поле. Рестарт в этот шаг не входит.
