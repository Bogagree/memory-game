# Header

## Scope

В хедере две кнопки. Обе доступны после загрузки, во время партии и после победы. Под открытой модалкой они недоступны вместе с остальной страницей.

| Кнопка | Поведение |
| --- | --- |
| Новая игра | [game.md](./game.md), раздел «Новая игра». Работает и когда несовпавшая пара ещё на таймере: таймер отменяется сразу. |
| Таблица лидеров | Открывает модалку рейтинга ([leaderboard.md](./leaderboard.md)). Поле, счётчики и таймер несовпадения не сбрасывает. |

Кнопка без текста обязана иметь `aria-label` с тем же смыслом.

## Шаги

- `feat/app-shell` — кнопки есть в разметке и их можно нажать (обработчики допустимы пустыми).
- `feat/leaderboard` — вторая кнопка открывает таблицу.
- `feat/new-game` — первая кнопка и такая же кнопка в модалке победы вызывают один рестарт.
