# QA — отчёты шагов

Отчёт шага: `docs/qa/<step>.md` (вердикт и заметки, без PNG в git). Имя файла — имя шага без префикса `feat/`: `feat/board` → `docs/qa/board.md`.

Для шага только с документацией отчёт не нужен.

Проверять поведение, не один скриншот. Минимум для игрового шага:

- сценарий из спеки шага проходит в браузере;
- соседний уже сделанный сценарий не сломан;
- в исходном `<body>` по-прежнему только `script`;
- в коде шага нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.

Перед сдачей отдельно пройти края из [game.md](../specs/game.md): двойной клик по одной карточке, третья карточка во время несовпадения, «Новая игра» пока тикает таймер, таблица лидеров во время несовпадения, одна запись на одну победу, 11-я победа не вытесняет лучший результат из топа неправильно.
