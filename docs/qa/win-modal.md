# QA — feat/win-modal

Статус: pass

Проверено в браузере на `http://127.0.0.1:4177/`.

- Первая карточка оставляет «0 ходов». Вторая другая даёт «1 ходов», обе открыты. Третья в этот момент не открывается, кнопки хедера не `disabled`, модалки нет. Через 1000 мс пара закрывается, счётчики остаются «1 ходов» и «0 из 8».
- Восемь пар открывают одно окно: заголовок «Победа», то же число ходов, что в хедере, кнопки «Новая игра» и «Закрыть». Фон затемнён, клик по карточке и по кнопке хедера попадает в `dialog`.
- Клик по заголовку и по числу ходов окно не закрывает. «Новая игра» в окне партию не сбрасывает.
- «Закрыть», клик по фону и Escape закрывают окно. Все 16 карточек остаются открытыми, счётчики те же. Повторный клик по карточке их не меняет и окно снова не открывает. «Таблица лидеров» окно не открывает. В `localStorage` записи нет.
- Пока окно открыто, прокрутка страницы не сдвигается. После закрытия возвращается позиция, которая была до окна.
- В исходном `body` только `script`. В `js/` нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.
