# QA — feat/flip-pair

Статус: pass

Проверено в браузере на `http://127.0.0.1:4175/`.

- Клик по закрытой карточке открывает её. Повторный клик по ней не открывает вторую.
- Вторая карточка той же пары остаётся открытой. Счётчики остаются «0 ходов» и «0 из 8».
- Клик по уже найденной карточке поле не меняет. Следующая закрытая карточка открывается.
- Две разные карточки остаются открытыми. Клик по третьей её не открывает.
- Кнопки хедера не `disabled`.
- В `js/` нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.
