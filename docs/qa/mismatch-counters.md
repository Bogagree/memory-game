# QA — feat/mismatch-counters

Статус: pass

Проверено в браузере на `http://127.0.0.1:4176/`.

- Первая карточка открывается, счётчики остаются «0 ходов» и «0 из 8».
- Вторая другая карточка даёт «1 ходов» и «0 из 8». Обе видны. Клик по третьей и по «Таблица лидеров» их не закрывает и не открывает третью. Кнопки хедера не `disabled`.
- Через 1000 мс несовпавшая пара закрывается. Счётчик ходов остаётся «1 ходов».
- Совпавшая пара остаётся открытой дольше 1000 мс. Счётчики становятся «2 ходов» и «1 из 8». Повторный клик по ней счётчики не меняет.
- Модалка победы не открывается. В `js/` нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.
