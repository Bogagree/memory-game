# QA — feat/board

Статус: pass

Проверено в браузере на `http://127.0.0.1:4173/`.

- После загрузки и после перезагрузки в поле 16 кнопок. Восемь `pairId`, каждый дважды. У карточек нет класса `card--flipped`, лицо скрыто, рубашка одна и та же.
- Счётчики: «0 ходов» и «0 из 8». «Новая игра» и «Таблица лидеров» не `disabled`. Клик по ним не меняет поле и счётчики.
- Клик по карточке не открывает её и не меняет счётчики.
- Класс `card--flipped` показывает лицо. Солнце и луна отличаются, рубашка лицо не выдаёт.
- На ширине окна около 770px и на 390px все 16 карточек видны, горизонтальной прокрутки нет.
- Исходный `body` по-прежнему содержит только `script`.
- В `js/` нет `innerHTML`, `insertAdjacentHTML`, `DOMParser`, `alert`, `confirm`, `prompt`.
